# TechTraill

Plataforma de cursos online desenvolvida como projeto de estudo, com telas de login, cadastro e navegação de conteúdo.

## Funcionalidades

Tela inicial de apresentação da plataforma. Cadastro de usuário. Login de usuário.

## Tecnologias utilizadas

HTML5, CSS3 e JavaScript.

## Como executar

Clone este repositório e abra o arquivo index.html no navegador.

## Planejamento

O planejamento completo do projeto está disponível no arquivo techtrail.pdf neste repositório.
